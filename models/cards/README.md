# 动态卡发布范围

`int_dynamic_v1.json`：三个已测节点的连续电压状态卡。状态初值由调用者显式给出，开通/关断增量逐次施加。两类机制为状态相关积分、有效边沿电荷；后者含有限开关过程，不能解释为纯MOS电荷注入。参数由27个隔离脉冲辨识，12个独立脉冲串验证。电压范围来自各节点训练覆盖，原统一0.46V上限及原始拒绝记录保存在实验目录。调用入口：`tmsp.dynamic.DynamicINT`。

`tr_dual_store_v1.json`：固定200ns周期、两存储交替的TR调度卡，L2标称节点、程序宽度20–100ns。100预热后5120周期/10240边沿，相位分配输入由理想激励表示，输出OR使用晶体管；不覆盖完整2%–98%占空比或输入解复用门。调用入口：`tmsp.dynamic.TwoBankTR`，以文件中的`config`及`scheduler`初始化。

MM电荷状态候选保留在`artifacts/mm_charge_candidate_v*`，尚未发布动态卡。v1独立留出FF P99超过1%FS；诊断和后续训练候选均单列，不覆盖该失败。

这些状态/调度扩展使用独立schema。DD-02 v1.1、原始静态卡及默认输出放置保持原定义；项目完整认证仍沿用冻结的63向量和占空比协议。
